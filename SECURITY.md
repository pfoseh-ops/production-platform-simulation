# Security policy

Do not open public issues containing credentials, account IDs, internal
hostnames, or vulnerability exploit details. Revoke exposed credentials first,
then report the issue privately to the repository owner.

CI blocks high and critical fixable container vulnerabilities, Terraform and
Kubernetes policy failures, and detected secrets. False-positive suppressions
must include a narrow scope and written rationale in the same change.
